# meeting-summary-YIJI
议迹是一款面向「持续跟进型会议」的桌面应用（Windows / macOS）。它以任务为主线，把散落的会议串成一条可回溯的时间线：开会时一键录音，结束后自动完成本地语音转写（内置 SenseVoiceSmall 模型，完全离线，支持说话人区分与标点恢复），再由 AI 将转写提炼为议题、决策、待办、遗留问题四类结构化纪要，可直接修改确认。最有特色的是它的「对比」能力——勾选同一任务下的任意两场会议，即可自动分析议题如何变化、决策如何演进、待办推进到哪一步、遗留问题是否解决，并生成改进总结；相邻会议若出现多处决策调整，时间线会自动标记「转折点」。全程数据只存在本机，无账号、无联网上传，AI 服务可选本地 Ollama（免费离线）或任意兼容端点（DeepSeek、通义、智谱等），隐私与可控性优先。
